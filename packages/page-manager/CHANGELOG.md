# 변경 기록

## 1.2.0 — 2026-10-26

선택한 이미지의 네 모서리를 마우스·터치로 드래그해 비율을 유지하며 크기를 조절합니다. 슬라이더 옆 현재 너비(%)를 직접 입력할 수 있고 슬라이더·버튼·드래그와 서로 동기화됩니다. 입력 범위는 10~100%이며 범위를 벗어난 값은 입력 완료 시 보정합니다. 모서리는 화살표 키로도 조절할 수 있고 한 번의 드래그는 실행 취소 한 번으로 되돌립니다. 조절 핸들은 본문 HTML에 저장하지 않습니다.

## 1.1.0 — 2026-10-26

게시글 화면 편집에서 이미지·YouTube·Vimeo·MP4·WebM을 선택해 너비를 10~100% 슬라이더, 25·50·75·100% 버튼 또는 자동 크기로 조절할 수 있습니다. 높이는 비율에 맞춰 조절되며, 미리보기·저장·재편집·공개 글에서도 크기를 유지합니다. HTML 코드의 안전한 미디어 너비(px·%)도 보존합니다. 화면 편집 중 YouTube·Vimeo 동영상이 일반 링크로 바뀌지 않도록 수정했습니다. 편집기에서 YouTube iframe을 생성할 때 출처 전송 정책과 재생 권한을 유지해 플레이어 구성 오류 153의 원인을 수정했습니다. 관리자 자산 버전도 갱신했습니다.

## 1.0.0 — 2026-10-23

기존 홈페이지의 관리자·로그인·게시글 관리·HTML 에디터·미디어·검수·보관·삭제를 공통 모듈로 분리했습니다. 사이트별 설정, 독립 정적 자산, Supabase/SQLite 어댑터와 새 사이트 시작 예제를 제공합니다. 기존 posts 레코드 및 양정베스트안과의 세션 식별자와 검수 규칙을 유지합니다.
